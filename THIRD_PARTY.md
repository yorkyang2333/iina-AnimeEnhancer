# Third-party components

AnimeEnhancer is based on [iina-anime4k](https://github.com/yorkyang2333/iina-AnimeEnhancer) by yorkyang2333 and retains that plugin's GPL-3.0 license. Development continues in the original repository, renamed to iina-AnimeEnhancer.

[Anime4K](https://github.com/bloc97/Anime4K) by bloc97 supplies the original GLSL shader chains. The `Anime4K` submodule is pinned to `7684e9586f8dcc738af08a1cdceb024cc184f426`. Its MIT license is included in installation packages as `licenses/Anime4K-MIT.txt`.

[AnimeJaNai](https://github.com/the-database/mpv-AnimeJaNai) by the-database supplies `2x_AnimeJaNai_HD_V3.1_Performance_SPANF3_b5f48_unshuffle_fp16.onnx` from revision `545ac129cf189ac5a68101d9f3d91c4d0fc78217`. `AnimeJaNai/ports/mpv-glsl/models/animejanai/model.json` records its source path and SHA-256. The original model and the preconverted coefficients in `AnimeJaNai/ports/mpv-glsl/shaders/` retain Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0). Conversion changes the execution representation and does not retrain the model. The full license is included as `AnimeJaNai/ports/mpv-glsl/models/animejanai/UPSTREAM-LICENSE` and packaged as `licenses/AnimeJaNai-CC-BY-NC-SA-4.0.txt`; provenance is packaged as `licenses/AnimeJaNai-model.json`, `licenses/AnimeJaNai-super-ultra-compact.json`, `licenses/AnimeJaNai-balanced.json` and `licenses/AnimeJaNai-sharp.json`. The plugin exposes the official Quality, Balanced and Performance labels. Quality and Balanced use the V3.1 Balanced HD model in this HD-only port; Performance uses V3.1 Performance. The fork also retains auxiliary Fast and Sharp conversions for future experiments.

The newly written model converter (`scripts/compile-animejanai.py`) and OpenGL numerical verification helpers (`tests/render-mpv.c`, `tests/verify-animejanai.py`) are additionally available under the MIT license in `AnimeJaNai/ports/mpv-glsl/LICENSE`, so they can be shared independently with the model project. The converted model coefficients keep their original license.
